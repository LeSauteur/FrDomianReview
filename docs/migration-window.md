# Окно перехода на v2

Цель: за одно короткое окно (≈20 минут) перевести идущую ревизию на `manifest.json`
и решения v2 в приватном репозитории `FrDomianReview-data`, ничего не потеряв.

**PR с v2 не мержить до окна**: как только он попадёт в `main`, Pages начнёт отдавать
новую страницу, которая читает репозиторий данных.

## До окна (без спешки)

- [ ] **Владелец:** создать по одному fine-grained токену на проверяющего
      (GitHub → Settings → Developer settings → Fine-grained tokens):
      Resource owner `LeSauteur`, Only select repositories → `FrDomianReview-data`,
      Permissions → Contents: Read and write, срок действия — до конца ревизии.
      Токены пока не раздавать.
- [ ] **Владелец:** проверить свой новый токен заранее — открыть PR-версию локально
      или просто убедиться, что токен видит репозиторий `FrDomianReview-data`.
- [ ] **Claude:** ветка v2 зелёная в CI; репозиторий `FrDomianReview-data` создан
      (в нём пустой файл-заглушка v2).

## Окно

1. [ ] **Владелец → проверяющим:** «Нажмите „Сохранить сейчас“, дождитесь „Сохранено онлайн“,
       сделайте „Экспорт JSON“ (резерв) и закройте вкладку ревизии».
2. [ ] **Владелец:** отозвать старые токены с доступом к `FrDomianReview`.
       Если кто-то не успел сохранить — его правки останутся в браузере и будут
       перенесены новой страницей автоматически (кэш v1 → v2).
3. [ ] **Claude:** забрать свежий `main`, убедиться, что после шага 1 новых коммитов
       «Update review decisions» нет.
4. [ ] **Claude:** `node scripts/scan-disk.mjs` — подтянуть изменения на Диске с момента подготовки.
5. [ ] **Claude:** `node scripts/migrate-decisions.mjs --in data/review-decisions.json --out v2.json`
       — сверка: число решений v1 = число голосов v2, все комментарии на месте;
       иначе скрипт падает и ничего не пишет.
6. [ ] **Claude:** записать `v2.json` в `FrDomianReview-data/review-decisions.json`,
       копию v1 — в `FrDomianReview-data/archive/review-decisions.v1.json`.
7. [ ] **Claude:** в ветке v2 удалить `data/review-decisions.json` из публичного репозитория
       (в истории git он останется), обновить `manifest.json`, смержить PR.
8. [ ] **Claude + владелец:** дождаться деплоя Pages (1–2 мин), открыть страницу с Ctrl+F5,
       ввести новый токен владельца:
       - счётчики совпадают с отчётом миграции;
       - поставить и снять голос на одном файле → «Сохранено онлайн»,
         в `FrDomianReview-data` появился коммит.
9. [ ] **Владелец → проверяющим:** раздать новые токены; «Обновите страницу (Ctrl+F5),
       введите новый токен в „GitHub token“, выберите себя в „Проверяющий“».
       Если у кого-то были несохранённые правки, страница покажет
       «Из прежней версии перенесено несохранённых изменений: N».

## Откат (если шаг 8 не прошёл)

- Revert merge-коммита в `main` → Pages вернёт v1-страницу.
- Вернуть `data/review-decisions.json` из истории (`git checkout <коммит до окна> -- data/review-decisions.json`).
- Выдать проверяющим токены на `FrDomianReview`, как раньше.
- Данные v2 из окна (если успели появиться) остаются в `FrDomianReview-data`; перенесу их вручную.
