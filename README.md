# FrDomianReview

Статический инструмент коллективной ревизии файлов публичного каталога «Домиан Франчайзинг» на Яндекс Диске.

Опубликованный интерфейс: <https://lesauteur.github.io/FrDomianReview/>.

## Данные

| Файл | Где | Что |
|---|---|---|
| `data/manifest.json` | этот репозиторий (публичный) | каталог документов: стабильный `id`, путь и ссылка на Диске, size, md5, sha256, даты, каталожные поля |
| `review-decisions.json` | приватный репозиторий `LeSauteur/FrDomianReview-data` | голоса проверяющих, решения арбитра, комментарии, закрепление папок |

### manifest.json

```jsonc
{
  "schema": 1,
  "generated_at": "…",
  "source": { "public_key": "…", "root_name": "Домиан Франчайзинг", "scanned_at": "…" },
  "sections": [],                       // целевые разделы новой структуры (этап 2)
  "documents": [{
    "id": "d_k3f9x2ab",                 // назначается один раз, не меняется
    "title": "…", "name": "….docx", "ext": "docx", "mime": "…",
    "section": null, "tags": [], "lifecycle": "pending", "actual_as_of": null, "owner": null,
    "disk": { "path": "/…", "resource_id": "…", "size": 0, "md5": "…", "sha256": "…",
              "created": "…", "modified": "…", "public_url": null, "viewer_url": "…",
              "missing_since": null },  // дата, с которой файла нет на Диске; документ не удаляется
    "history": { "original_path": "/…", "previous_paths": [] }
  }]
}
```

Обновление по Диску (публичный API, без OAuth):

```bash
node scripts/scan-disk.mjs
```

Сканер сопоставляет файлы с документами по `resource_id`, затем по текущему и прежним путям, затем по md5 (если совпадение единственное). Каталожные поля не перезаписываются.

### review-decisions.json (v2)

```jsonc
{
  "version": 2,
  "updated_at": "…",
  "assignments": { "/Руководитель": { "reviewers": ["Марина Олеговна"], "at": "…" } },
  "files": {
    "d_k3f9x2ab": {
      "votes": { "Андрейченко Валерий": { "status": "KEEP", "at": "…" } },   // status: null — голос снят
      "resolution": { "status": "ARCHIVE", "by": "Егупов Алексей", "at": "…" },
      "outcome": { "status": "DELETED", "by": "Марина Олеговна", "at": "…" },   // DELETED | UPDATED | null
      "comments": [{ "id": "…", "author": "…", "text": "…", "created_at": "…" }]
    }
  }
}
```

Итоговый статус файла: решение арбитра, если оно есть; иначе единственный статус среди голосов (одного голоса достаточно); два и более разных статуса — **конфликт**. Голоса никогда не затираются решением арбитра. Арбитр — Егупов Алексей.

`outcome` — отметка о выполнении («Удалено», «Актуализировано»), отдельная от голосов: итог ревизии не меняется. Ставит любой проверяющий. Файл, которого сканер не нашёл на Диске, считается удалённым автоматически.

Слияние при синхронизации: голос каждого проверяющего, решение арбитра и отметка о выполнении — по более позднему `at`, комментарии объединяются по `id`.

## Использование

Выберите себя в поле «Проверяющий». Кнопка статуса ставит ваш голос; повторное нажатие снимает его. Под файлом видны голоса всех проверяющих. При конфликте арбитр видит поле «Решение арбитра». Когда итог — «Удалить»/«Дубликат» или «Обновить», на карточке появляется кнопка «✓ Отметить: Удалено / Актуализировано».

Фильтры: по статусу, «Конфликты», «К выполнению», «Выполнено», по типу файла и по размеру. Вид «Список по размеру» показывает все файлы одним списком, начиная с самых тяжёлых.

Каждое изменение сразу сохраняется в `localStorage`, а в репозиторий данных отправляется раз в 15 секунд, после 10 изменений или по кнопке «Сохранить сейчас».

Несохранённые изменения из прежней версии страницы (кэш v1) переносятся автоматически при загрузке.

## Доступ к GitHub

Каждому проверяющему выдаётся fine-grained personal access token:

- Resource owner: `LeSauteur`;
- Repository access: **только** `LeSauteur/FrDomianReview-data`;
- Repository permissions: `Contents: Read and write`.

Токен хранится только в `sessionStorage` браузера и не даёт доступа к коду инструмента. Без токена страница работает с локальной копией.

## Экспорт и импорт

«Экспорт JSON» сохраняет файл v2. «Импорт JSON» принимает и v2, и старые файлы v1 (ключ — путь), включая пути до переноса файлов.

## Скрипты

```bash
node scripts/scan-disk.mjs                              # обновить manifest.json по Диску
node scripts/migrate-decisions.mjs --in v1.json --out v2.json   # перевод решений v1 → v2 со сверкой
node --test                                             # тесты
```

Порядок перехода с v1 описан в [docs/migration-window.md](docs/migration-window.md).

**Статус DELETE сам по себе никогда не удаляет файл.** В этом репозитории нет OAuth Яндекс Диска.
